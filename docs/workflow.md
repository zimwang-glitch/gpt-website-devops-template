# GPT Website Maintenance Workflow

## Objective

Use GPT as an intelligent website development assistant while keeping GitHub as the single source of truth.

## Standard workflow

Understand → Inspect → Plan → Modify → Test → Commit → Deploy → Verify

## Roles

GPT assists with:

- content planning and editing
- front-end modifications
- code review
- deployment troubleshooting
- documentation maintenance

## Change types

### Content update

Examples:
- news
- publications
- team information

Process:

content source → update → build check → deploy → verify

### Design update

Process:

requirement → UI analysis → component modification → visual verification

### Infrastructure update

Process:

domain → DNS → certificate → hosting → deployment → public verification

## Governance rules

- GitHub repository is the authoritative version.
- Production deployment must be traceable.
- Infrastructure changes require explicit confirmation.
- Content and presentation should remain separated.
