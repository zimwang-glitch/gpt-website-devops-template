# Website Maintenance SOP

## Content update

Example: news, publications, team information.

Workflow:

Locate data source → modify content → build test → deploy → verify

## Design update

Workflow:

Analyze UI → define expected experience → modify component/style → visual verification

## Infrastructure troubleshooting

Check in order:

Domain → DNS → SSL → Hosting → Deployment → Code

## Rollback principle

Do not manually edit production files. Use version control history for recovery.
