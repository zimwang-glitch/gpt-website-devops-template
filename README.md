# GPT Website DevOps Assistant

An AI-assisted workflow framework for maintaining academic websites through natural language interaction.

## Concept

User request
→ GPT assistant
→ GitHub repository
→ CI/CD deployment
→ Cloud hosting
→ Public website

## Core principles

1. GitHub is the single source of truth.
2. Production deployment should be automated.
3. Every modification must be traceable.
4. Infrastructure changes require explicit confirmation.
5. Content should be separated from presentation.

## Designed for

- Academic laboratory websites
- Research center websites
- Faculty profiles
- Scientific communication websites

## Workflow

Understand → Inspect → Plan → Modify → Test → Commit → Deploy → Verify
